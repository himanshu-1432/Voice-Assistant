# AI Voice Assistant

An AI-powered voice assistant being built in Python. The goal of this project is to create a conversational assistant capable of understanding speech, maintaining context across conversations, and performing actions through external tools.

## Current Status

🚧 Work in Progress

This project is currently in the early development phase. Core architecture and project setup are being established before implementing individual features.

## Planned Features

- Speech-to-Text (Whisper)
- Conversational AI integration
- Text-to-Speech responses
- Conversation memory
- Tool calling
- Retrieval-Augmented Generation (RAG)
- Support for local and cloud LLMs

## Tech Stack

- Python
- FastAPI
- Whisper
- OpenAI / Gemini APIs
- SQLite
